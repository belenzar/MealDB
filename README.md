# 🍽️ MealDB App

Aplicación web desarrollada con **JavaScript vanilla** que consume la API pública de **TheMealDB** para buscar y visualizar recetas de comidas de forma dinámica.

El objetivo del proyecto fue practicar el **consumo de APIs**, la manipulación del **DOM** y el uso de **JavaScript moderno**.

---

## 🚀 Demo
🔗 https://meal-db-lilac.vercel.app/

---

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
- API TheMealDB

---

## 📌 Funcionalidades
- Búsqueda de comidas por nombre
- Renderizado dinámico de resultados
- Visualización de información detallada de cada receta
- Consumo de API externa con `fetch`
- Manejo de estados de carga (loading)
- Diseño responsive
